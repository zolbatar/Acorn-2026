# JetBrains Mono

`JetBrainsMono-Regular.ttf` is the static Regular face from JetBrains Mono
2.304, downloaded from the official release archive:

<https://github.com/JetBrains/JetBrainsMono/releases/download/v2.304/JetBrainsMono-2.304.zip>

The font is embedded for BASIC `TEXT=MODERN` guest output. Its original
`OFL.txt` is preserved as [`LICENSE-JetBrainsMono.txt`](LICENSE-JetBrainsMono.txt).
The SIL Open Font License 1.1 permits bundling and redistribution with this
application. The desktop furniture continues to use Inter.
