# Glossy BASIC and text icons

Assets: `basic-glossy-v1-1024.png` and `text-glossy-v1-1024.png`. Each is 1024 × 1024 with transparency. Created using built-in image generation with the user's RISC OS screenshot and glossy directory style reference, then downsampled to the exact requested dimensions with sips. Installed in the modern Filer renderer: Text (&FFF / file_fff) uses the text icon; BASIC (&FFB / file_ffb) uses the BASIC icon. Catalogue filetype, not the filename extension or launch action, chooses the icon. Assets are decoded once, trimmed to visible bounds and smoothly fitted to the large or compact icon slot. Unknown types retain generic artwork.

Exact source lettering: '10 REM BASIC' newline '20 FOR I=1' newline '30 PRINT I' newline '40 NEXT I' newline '50 END'. All text within tile, strong white-on-blue contrast, no other text or label below. Retain simple authentic RISC OS BASIC program-icon feel from screenshot, not a terminal window, no titlebar, no buttons, no folder, no pen. Glossy polished early-computer 3D icon style matching companion directory/acorn/disk set, subtle specular highlight without obscuring source. Centered single square tile occupying 80% of square canvas width and height, equal transparent margins. Genuine transparent alpha background, no backdrop, no cast shadow, no baked checkerboard. Output requested exactly 1024 x 1024 RGBA PNG.

## Text prompt

Reference 2 supplies glossy material/rendering style only: polished molded surfaces, softly beveled edges, rich shaded depth and clean upper-right specular highlights. Single straight-on near-square white/ivory document plaque with a thin dark charcoal border and subtle bevel. Many orderly short dark horizontal typographic bars arranged as text lines, varied lengths and small spaces, no readable words required. Across its right half lies a glossy saturated blue fountain pen angled from bottom-left toward upper-right, with a small golden nib at the lower end near bottom center and upper end near document upper-right corner. Match the reference's recognizable composition and proportions closely, keep document square rather than tall page, no folded corner, no notebook binding, no second page, no badges. Render in the same glossy early-computer icon style as companion directory, acorn and hard disk. Single centered composition occupying about 80% canvas width and height with equal transparent margins; no label beneath, no other objects, no cast shadow, no backdrop or baked checkerboard. Genuine transparent RGBA PNG, requested output exactly 1024 x 1024.
